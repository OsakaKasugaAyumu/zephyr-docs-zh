脉宽调制接口（Pulse Width Modulation (PWM)）

非官方简体中文译本 · H05 · 英文基线 4.5.99 · 全站目录（79 篇） · H 批目录 · 本页英文原文

概述

脉宽调制（PWM）通过改变数字信号的占空比来编码信息或调节输出功率。信号以固定频率在高、低电平之间切换，每个周期内高电平所占的比例称为占空比（duty cycle）。

PWM 在嵌入式系统中的常见用途：

  • LED 亮度控制：用占空比调节人眼感受到的亮度。

  • 直流电机调速：平均电压与占空比成正比。

  • 舵机定位：用脉冲宽度表示目标角度。

  • 产生音调：改变频率以产生可听音调。

  • 功率转换：例如降压／升压转换器及 D 类放大器。

PWM 信号参数

PWM 信号由三个量描述：

  • 周期（period）：一个完整开关循环的时长，单位为纳秒。

  • 脉冲宽度（pulse width）：高电平（有效）部分的持续时间，单位为纳秒。

  • 占空比：脉冲宽度与周期的比值，以百分数表示；50% 表示信号有半个周期为高电平。

Zephyr PWM 驱动模型

每个 PWM 控制器提供一个或多个独立的通道。通道从零编号，每个通道驱动一个输出引脚。

所有 PWM 驱动都实现 include/zephyr/drivers/pwm.h 中的同一套 API。核心函数 pwm_set() 设置通道的周期与脉冲宽度。下列辅助宏将常用时间／频率单位转换为纳秒：

  • PWM_HZ：频率以 Hz 表示（如 PWM_HZ(1000) 对应 1 ms 周期）。

  • PWM_KHZ：频率以 kHz 表示。

  • PWM_USEC：周期或脉冲宽度以微秒表示。

  • PWM_MSEC：周期或脉冲宽度以毫秒表示。

设备树配置

设备树通过 pwms 属性描述 PWM 输出。每一项都指定控制器 phandle、通道号、以纳秒计的周期，以及可选的极性标志：

/ {
    my_node {
        pwms = <&pwm0 0 PWM_MSEC(20) PWM_POLARITY_NORMAL>;
        pwm-names = "servo";
    };
};

在 C 中，用 PWM_DT_SPEC_GET 系列宏取得该配置：

static const struct pwm_dt_spec servo =
    PWM_DT_SPEC_GET(DT_NODELABEL(my_node));

用法示例

用 pwm_dt_spec 设置占空比：

#include <zephyr/drivers/pwm.h>

static const struct pwm_dt_spec led_pwm =
    PWM_DT_SPEC_GET(DT_ALIAS(pwm_led0));

int set_led_brightness(uint8_t percent)
{
    if (!device_is_ready(led_pwm.dev)) {
        return -ENODEV;
    }

    /* pulse = period * duty_cycle / 100 */
    uint32_t pulse = led_pwm.period / 100 * percent;

    return pwm_set_dt(&led_pwm, led_pwm.period, pulse);
}

设置舵机位置（在 20 ms 周期内产生 1–2 ms 脉冲）：

#include <zephyr/drivers/pwm.h>

#define SERVO_PERIOD_NS   PWM_MSEC(20)
#define SERVO_MIN_PULSE   PWM_USEC(1000)
#define SERVO_MAX_PULSE   PWM_USEC(2000)

int set_servo_angle(const struct device *pwm_dev, uint32_t channel,
                    uint8_t angle_deg)
{
    uint32_t pulse = SERVO_MIN_PULSE +
        (SERVO_MAX_PULSE - SERVO_MIN_PULSE) * angle_deg / 180;

    return pwm_set(pwm_dev, channel, SERVO_PERIOD_NS, pulse,
                   PWM_POLARITY_NORMAL);
}

PWM 捕获

有些 PWM 控制器支持输入捕获（input capture），即测量输入信号的周期或脉冲宽度，可用于解码遥控接收器、传感器等外部来源的 PWM 信号。

使用 pwm_configure_capture() 和 pwm_enable_capture() 配置并启用捕获：

void pwm_capture_cb(const struct device *dev, uint32_t channel,
                    uint32_t period_cycles, uint32_t pulse_cycles,
                    int status, void *user_data)
{
    if (status != 0) {
        return;
    }
    /* convert cycles to nanoseconds using pwm_get_cycles_per_sec() */
}

/* configure for single-shot capture of both period and pulse */
pwm_configure_capture(dev, channel,
                      PWM_CAPTURE_TYPE_BOTH | PWM_CAPTURE_MODE_SINGLE,
                      pwm_capture_cb, NULL);
pwm_enable_capture(dev, channel);
