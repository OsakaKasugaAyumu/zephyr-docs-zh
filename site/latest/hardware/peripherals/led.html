LED 驱动接口（Light-Emitting Diode (LED)）

非官方简体中文译本 · H04 · 英文基线 4.5.99 · 全站目录（94 篇） · H 批目录 · 本页英文原文

概述

LED API 可访问独立 LED 和灯带，用一组通用操作屏蔽 GPIO 直接驱动、PWM 调光、专用控制芯片和可寻址灯带之间的差异。

提供两个相关子系统：

  • LED：控制独立或经控制器驱动的 LED，支持开关、亮度、颜色和闪烁。

  • LED 灯带（LED Strip）：面向 WS2812、APA102 等可寻址灯串，每个像素有独立颜色值。

LED 操作

各驱动可实现下列操作的一个子集。底层不支持某项可选操作时，调用返回 -ENOSYS。

必选操作（至少实现其中一种）：

  • led_on()／led_off()：将 LED 完全点亮或熄灭。

  • led_set_brightness()：亮度范围为 0 至 LED_BRIGHTNESS_MAX（100）；如实现，led_on() 和 led_off() 也会自动使用它。

译校注 · H04-01

led_on() 和 led_off() 优先调用驱动对应的 on 或 off 回调。只有该回调缺失时，才退回 set_brightness，分别使用 LED_BRIGHTNESS_MAX 或 0。相应回调与亮度回调都没有时，返回 -ENOSYS。

固定版本依据：Zephyr 1b1b2e0cdca4

led.h：350–360；led.h：378–389

可选操作：

  • led_blink()：按指定的点亮／熄灭时长开始闪烁。

  • led_set_color()：设置多色 LED 各通道的颜色值。

  • led_get_info()：获取指定 LED 的 led_info，其中包括标签、索引和颜色映射。

  • led_write_channels()：写入一段连续的原始通道值，供将 LED 暴露为通道数组的驱动使用。

LED 索引

驱动通过从零开始的 led 索引寻址每个 LED。多色 LED 只占一个索引，各通道的值一起传给 led_set_color()。

多色 LED 的通道顺序由 led_info 的 color_mapping 字段描述。每项均为 include/zephyr/dt-bindings/led/led.h 中定义的一个 LED_COLOR_ID_* 值：

  • LED_COLOR_ID_WHITE

  • LED_COLOR_ID_RED

  • LED_COLOR_ID_GREEN

  • LED_COLOR_ID_BLUE

  • LED_COLOR_ID_AMBER

  • LED_COLOR_ID_VIOLET

  • LED_COLOR_ID_YELLOW

  • LED_COLOR_ID_IR

设备树配置

简单 LED 通常表示为 LED 控制器的子节点，可以用设备树别名引用：

/ {
    aliases {
        led0 = &status_led;
    };

    leds {
        compatible = "gpio-leds";
        status_led: led_0 {
            gpios = <&gpio0 13 GPIO_ACTIVE_HIGH>;
            label = "Status LED";
        };
    };
};

多色 LED 通过 color-mapping 属性表示颜色信息，使用 include/zephyr/dt-bindings/led/led.h 定义的 LED_COLOR_ID_* 值。

用法示例

通过设备树别名进行基本开关控制：

#include <zephyr/drivers/led.h>
#include <zephyr/devicetree.h>

#define LED_NODE DT_ALIAS(led0)
static const struct device *led_dev = DEVICE_DT_GET(DT_PARENT(LED_NODE));
static const uint32_t led_idx = DT_NODE_CHILD_IDX(LED_NODE);

int turn_on_status_led(void)
{
    if (!device_is_ready(led_dev)) {
        return -ENODEV;
    }
    return led_on(led_dev, led_idx);
}

设置亮度（0–100）：

/* Dim the LED to 25% brightness */
led_set_brightness(led_dev, led_idx, 25);

以亮 500 ms、灭 500 ms 的节奏闪烁：

int err = led_blink(led_dev, led_idx, 500, 500);

if (err == -ENOSYS) {
    /* Driver does not implement blink natively */
}

设置多色（RGB）LED 的颜色：

/* Order of the values must match the color_mapping reported by
 * led_get_info(); for a standard RGB mapping the order is R, G, B.
 */
const uint8_t purple[] = { 0x80, 0x00, 0x80 };

led_set_color(led_dev, led_idx, ARRAY_SIZE(purple), purple);
