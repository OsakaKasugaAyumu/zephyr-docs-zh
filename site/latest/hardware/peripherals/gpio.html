通用输入输出（GPIO）

非官方简体中文译本 · 英文基线 4.5.99 · B09 · 全站目录（94 篇） · B 批目录 · 本页英文原文

概述

通用输入输出（General-Purpose Input/Output，GPIO）是没有固定专用功能的数字信号引脚，可通过软件配置为输入或输出。

GPIO API 提供了访问此类引脚的统一方法。应用可以配置引脚方向、读取或写入状态，以及管理中断。主要功能包括：

引脚配置

可将引脚配置为输入、输出或断开连接。支持配置内部上拉／下拉电阻和驱动强度。

数据访问

读取输入值、写入输出值。

中断

可为引脚配置上升沿、下降沿、低电平或高电平中断，并注册回调函数来处理中断。

与设备树集成

GPIO 通常在设备树（Devicetree）中定义。驱动和应用可以通过 gpio_dt_spec 引用它们，而不必写死具体硬件。

设备树配置

在设备树中，具有 gpio-controller 属性的节点定义 GPIO 控制器。#gpio-cells 属性通常指定用两个单元（cell）描述一个 GPIO：引脚号和标志。

GPIO 控制器定义示例：

gpio0: gpio@40022000 {
    compatible = "ti,cc13xx-cc26xx-gpio";
    reg = <0x40022000 0x400>;
    interrupts = <0 0>;
    gpio-controller;
    #gpio-cells = <2>;
};

引用 GPIO 的示例：

leds {
    compatible = "gpio-leds";
    led0: led_0 {
        gpios = <&gpio0 25 GPIO_ACTIVE_HIGH>;
        label = "Green LED";
    };
};

基本操作

GPIO 操作通常使用 gpio_dt_spec 结构，其中保存了设备树指定的 GPIO 引脚信息。

通常用 GPIO_DT_SPEC_GET 宏或其变体填充此结构。

为别名为 led0 的引脚填充 gpio_dt_spec 结构。
#define LED0_NODE DT_ALIAS(led0)
static const struct gpio_dt_spec led = GPIO_DT_SPEC_GET(LED0_NODE, gpios);

随后即可通过 gpio_dt_spec 结构操作 GPIO。

将 GPIO 引脚（即上例中的 led）配置为输出，初始为非活动状态，然后切换至有效电平。
int ret;

ret = gpio_pin_configure_dt(&led, GPIO_OUTPUT_INACTIVE);
if (ret < 0) {
    return ret;
}

ret = gpio_pin_set_dt(&led, 1);
if (ret < 0) {
    return ret;
}

用 gpio_dt_spec 结构进行 GPIO 基本操作的完整示例见 Blinky：LED 闪烁。

也可直接对 GPIO 控制器设备操作，此时应选用以设备指针为参数的 GPIO API，例如用 gpio_pin_configure() 代替 gpio_pin_configure_dt()。

GPIO 预占（GPIO hogs）

GPIO hog 可在系统初始化时自动配置引脚。它适合必须在启动时进入指定状态（例如复位线、电源使能线）、但不需要应用在运行时控制的引脚。

hog 在设备树中定义为 GPIO 控制器节点的子节点。

  • gpio-hog 属性将该节点标记为 hog。

  • gpios 属性指定引脚及其有效状态。

  • 用 input、output-low 或 output-high 之一指定引脚配置。

设备树覆盖文件示例：

&gpio0 {
    hog1 {
        gpio-hog;
        gpios = <1 GPIO_ACTIVE_LOW>;
        output-high;
    };

    hog2 {
        gpio-hog;
        gpios = <2 GPIO_ACTIVE_HIGH>;
        output-low;
    };
};

如果除了系统初始化时自动设置初始状态外，还需要在运行时控制此引脚，可以考虑使用稳压器（Regulators）及 regulator-fixed 设备树节点。

配置选项

主要配置选项：

  • CONFIG_GPIO

  • CONFIG_GPIO_SHELL

  • CONFIG_GPIO_GET_DIRECTION

  • CONFIG_GPIO_GET_CONFIG

  • CONFIG_GPIO_HOGS

  • CONFIG_GPIO_ENABLE_DISABLE_INTERRUPT
