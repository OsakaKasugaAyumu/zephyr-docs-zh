串口接口（Universal Asynchronous Receiver-Transmitter (UART)）

非官方简体中文译本 · H07 · 英文基线 4.5.99 · 全站目录（94 篇） · H 批目录 · 本页英文原文

概述

Zephyr 提供三种访问 UART 外设的方式，各自采用的 API 分列如下：

  1. 轮询接口（Polling API）

  2. 中断驱动 API

  3. 使用直接存储器访问（DMA）的异步 API

轮询是最基本的 UART 访问方式。读函数 uart_poll_in() 不阻塞，有数据则读出字符，无有效数据时返回 -1。写函数 uart_poll_out() 会阻塞，线程等待给定字符发送完毕。

译校注 · H07-01

uart_poll_in(dev, &ch) 不阻塞。成功时函数返回 0，并把收到的字符写入 ch；无数据时返回 -1。不支持该操作或已启用异步接收时，还可能返回其他负错误码。不要把函数的返回值当作字符。

固定版本依据：Zephyr 1b1b2e0cdca4

uart.h：342–358

采用中断驱动 API 时，较慢的通信可在后台进行，线程则继续处理其他任务。线程与 UART 驱动之间可以通过内核的数据传递机制通信。

异步 API 使用 DMA 在后台收发数据，数据搬运过程无须中断 MCU，但配置比其他方法复杂。

警告

对于同一个 UART 外设实例，不应同时使用中断驱动 API 和异步 API。两者都依赖硬件中断，同时使用其回调会相互干扰。默认启用 CONFIG_UART_EXCLUSIVE_API_CALLBACKS，确保一次只有一种 API 的回调有效。

配置选项

轮询 API（默认）、中断驱动 API 或异步 API 哪些可用，取决于 Kconfig 选项。只启用需要的特性，以减少内存占用。

相关配置选项：

  • CONFIG_SERIAL

  • CONFIG_UART_INTERRUPT_DRIVEN

  • CONFIG_UART_ASYNC_API

  • CONFIG_UART_WIDE_DATA

  • CONFIG_UART_USE_RUNTIME_CONFIGURE

  • CONFIG_UART_LINE_CTRL

  • CONFIG_UART_DRV_CMD
