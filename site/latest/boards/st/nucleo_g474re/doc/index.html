概述

Nucleo G474RE 搭载基于 Arm Cortex-M4 的 STM32G474RE 微控制器（MCU），支持多种连接方式和配置。主要特点如下：

  • 采用 LQFP64 封装的 STM32 微控制器

  • 兼容 Arduino Uno V3 接口

  • 板载 ST-LINK/V3E 调试器和编程器，带串行线调试（SWD）连接器

  • 多种供电方式：

    • USB VBUS 或外部电源（3.3 V、5 V、7–12 V）

    • 电源管理接入点

  • 三个 LED：USB 通信指示灯（LD1）、电源指示灯（LD3）、用户 LED（LD2）

  • 两个按键：RESET 和 USER

更多信息见 Nucleo G474RE 产品页。

硬件

STM32G474RE SoC 提供以下硬件模块：

  • 通过 FlexPowerControl 实现超低功耗（待机模式最低 28 nA；运行模式最低 84 µA/MHz）

  • 内核：32 位 ARM® Cortex®-M4 CPU，带浮点单元（FPU），最高 170 MHz

  • 时钟源：

    • 4–48 MHz 外部高速晶体振荡器（HSE）

    • 为 RTC 提供时钟的 32 kHz 外部低速晶体振荡器（LSE）

    • 出厂校准的内部 16 MHz RC 振荡器（±1%）

    • 内部低功耗 32 kHz RC 振荡器（±5%）

    • 两个锁相环（PLL），用于系统时钟、USB、音频及 ADC

  • 带硬件日历、闹钟和校准功能的实时时钟（RTC）

  • 14 个定时器：

    • 1 个 32 位和 2 个 16 位定时器，支持最多四路输入捕获／输出比较／PWM，或脉冲计数及正交（增量）编码器输入

    • 2 个 16 位、8 通道高级电机控制定时器，支持最多 8 路 PWM、死区生成及紧急停止

    • 1 个 16 位定时器，支持两路 IC/OC、一路 OCN/PWM、死区生成及紧急停止

    • 2 个 16 位定时器，支持 IC/OC/OCN/PWM、死区生成及紧急停止

    • 2 个看门狗定时器（独立看门狗和窗口看门狗）

    • 2 个 16 位基本定时器

    • SysTick 系统节拍定时器

    • 1 个低功耗定时器

  • 最多 86 个高速 I/O，大多数可耐受 5 V

  • 存储器

    • 最多 512 KB 单存储体（single-bank）闪存，支持专有代码读出保护

    • 最多 128 KB SRAM，其中 32 KB 支持硬件奇偶校验

  • 丰富的模拟外设（独立供电）

    • 2 个 12 位 ADC，5 MSPS；通过硬件过采样最高可达 16 位，功耗 200 µA/MSPS

    • 4 个 12 位 DAC，支持低功耗采样保持

    • 3 个运算放大器，内置可编程增益放大器（PGA）

    • 4 个超高速轨到轨模拟比较器

  • 16 个通信接口

    • 1 个支持可变数据速率的 FDCAN 控制器

    • 3 个 I2C，支持 FM+（1 Mbit/s）和 SMBus/PMBus

    • 4 个 USART（ISO 7816、LIN、IrDA、调制解调器）

    • 1 个 LPUART

    • 3 个 SPI，其中 2 个复用半双工 I2S 接口

    • 1 个 SAI（串行音频接口）

    • USB 2.0 全速接口，支持 LPM 和 BCD

    • IRTIM（红外接口）

    • USB Type-C® / USB 电力传输控制器（UCPD）

  • 12 通道 DMA 控制器

  • 真随机数生成器（RNG）

  • CRC 计算单元、96 位唯一标识符

  • 开发支持：串行线调试（SWD）、JTAG、嵌入式跟踪宏单元（Embedded Trace Macrocell）*

  • STM32G4 参考手册

连接与 I/O

Nucleo G474RE 有 6 个 GPIO 控制器，负责引脚复用、输入输出、上拉等功能。

详情请参阅STM32G4 Nucleo-64 开发板用户手册。

Zephyr 默认外设引脚映射：

  • UART_1_TX : PC4

  • UART_1_RX : PC5

  • LPUART_1_TX : PA2

  • LPUART_1_RX : PA3

  • I2C_1_SCL : PB8

  • I2C_1_SDA : PB9

  • SPI_1_NSS : PB6

  • SPI_1_SCK : PA5

  • SPI_1_MISO : PA6

  • SPI_1_MOSI : PA7

  • SPI_2_NSS : PB12

  • SPI_2_SCK : PB13

  • SPI_2_MISO : PB14

  • SPI_2_MOSI : PB15

  • SPI_3_NSS : PA15

  • SPI_3_SCK : PC10

  • SPI_3_MISO : PC11

  • SPI_3_MOSI : PC12

  • PWM_2_CH1 : PA5（可能与 SPI1 冲突）

  • PWM_3_CH1 : PB4

  • USER_PB : PC13

  • LD2 : PA5

  • ADC1_IN1 : PA0

  • DAC1_OUT1 : PA4

  • FDCAN1_RX: PA11

  • FDCAN1_TX: PA12

系统时钟

Nucleo G474RE 可使用内部振荡器、外部振荡器或主 PLL 提供系统时钟。默认使用 16 MHz 内部高速振荡器驱动 PLL，系统时钟为 150 MHz。选择升频模式（boost mode）后可提高至 170 MHz。

串口

Nucleo G474RE 有 3 个 U(S)ART。Zephyr 控制台默认通过 LPUART1 输出，串口设置为 115200 8N1。

注意：低功耗模式下，如果 MCU 使用 LSE（32.768 kHz）作为时钟源，LPUART1 的波特率最高为 9600。

nucleo_g474re 支持以下执行后端（runner）及对应的 west 命令。

flash debug debugserver attach reset rtt
jlink ✅ ✅ ✅ ✅ ✅ ✅
openocd ✅ ✅（默认） ✅ ✅ ✅
pyocd ✅ ✅ ✅ ✅ ✅ ✅
stm32cubeprogrammer ✅（默认）

Nucleo G474RE 板载 ST-LINK/V3E 调试接口。

针对 nucleo_g474re 开发板配置的应用可按常规方式构建和烧写，详见构建应用和运行应用。

烧写（Flashing）

此开发板默认通过 west 的 STM32CubeProgrammer 后端烧写，因此需要先完成安装。

也可通过 --runner（或 -r）选项改用 OpenOCD 或 pyOCD 烧写开发板：

$ west flash --runner openocd
$ west flash --runner pyocd

将应用烧写到 Nucleo G474RE

通过 USB 端口将 Nucleo G474RE 连接到主机，再运行串口终端程序连接开发板。

$ minicom -D /dev/ttyACM0

现在构建并烧写应用。下面以 Hello World 为例。

# From the root of the zephyr repository
west build -b nucleo_g474re samples/hello_world
west flash

控制台应显示以下消息：

$ Hello World! arm

调试（Debugging）

可按常规方式调试应用。下面以 Hello World 应用为例。

# From the root of the zephyr repository
west build -b nucleo_g474re samples/hello_world
west debug
