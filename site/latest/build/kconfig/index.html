配置系统（Kconfig）

非官方简体中文译本 · 英文基线 4.5.99 · C08 · 全站目录（79 篇） · C 批目录 · 本页英文原文

Zephyr 内核与各子系统可在构建时配置，以适应具体应用和平台。Zephyr 与 Linux 内核都采用 Kconfig，目的是让用户无须修改源码就能调整配置。

配置选项通常称为符号（symbols），在 Kconfig 文件中定义。文件还会声明符号之间的依赖，决定哪些配置组合有效。符号可分组放入菜单和子菜单，便于在交互界面中浏览。

Kconfig 输出头文件 autoconf.h，其中的宏可在编译时判断。未使用的功能可以不编入镜像，从而节省空间。
