ISO-TP 库示例（ISO-TP library）

非官方简体中文译本 · I08 · 英文基线 4.5.99 · 全站目录（79 篇） · I 批目录 · 本页英文原文

在 GitHub 上浏览源码

概述

本例演示如何使用 ISO-TP 库（ISO-TP library）。

两块板交换两种消息：长消息的块大小（BS）为 8 帧，短消息的最小间隔（STmin）为 5 毫秒。

短消息的发送调用不阻塞，长消息的发送调用会阻塞。

构建与运行

以下说明适用于带集成 CAN 控制器的板，例如 NXP TWR-KE18F 或 Nucleo-F746ZG。

以 NXP TWR-KE18F 为例：

# From the root of the zephyr repository
west build -b twr_ke18f samples/subsys/canbus/isotp
west flash

硬件要求

  • 两块支持 CAN 总线且已相互连接的开发板
