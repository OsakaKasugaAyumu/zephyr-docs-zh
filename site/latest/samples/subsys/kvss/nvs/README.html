NVS 示例：保存重启计数（Non-Volatile Storage）

非官方简体中文译本 · J05 · 英文基线 4.5.99 · 全站目录（94 篇） · J 批目录 · 本页英文原文

在 GitHub 上浏览源码

概述

这个小程序演示如何用 NVS 模块在非易失性存储器（闪存）中保存数据。每次重启，应用都会递增计数器并将它写入闪存；再次启动时，应用会读回已保存的重启次数。

译校注 · J05-U01

计数发生在示例主动重启前

示例先读回计数，在倒计时结束、即将主动重启时才递增并保存。达到配置的上限后，示例将计数清零并结束；它并不是每次掉电或外部复位都自动加一的通用重启计数器。

硬件要求

  • 一块支持闪存的开发板。

译校注 · J05-U02

开发板还需要可用的存储分区

示例选择 storage_partition 并检查闪存设备是否就绪，再用查到的闪存页大小配置 3 个扇区。应为该分区预留相应空间；3 是本示例的配置，不是 NVS 通用的最少扇区数。

构建与运行

示例可为多个平台构建。以下命令为 nrf51dk/nrf51822 开发板构建应用。

west build -b nrf51dk/nrf51822 samples/subsys/kvss/nvs
west flash

将镜像烧写到开发板后，控制台会显示重启计数。开发板会重启数次，可以看到计数逐次增加。
