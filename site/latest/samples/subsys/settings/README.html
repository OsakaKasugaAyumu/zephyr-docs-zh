Settings API 示例：加载与保存配置（Settings API）

非官方简体中文译本 · J07 · 英文基线 4.5.99 · 全站目录（94 篇） · J 批目录 · 本页英文原文

在 GitHub 上浏览源码

概述

这个小程序演示如何使用 Settings 运行时配置模块。应用使用不同的 Settings 方法，从持久化存储加载配置值，再将这些值导出到持久化存储。示例也展示了如何实现并注册模块的处理程序。

硬件要求

  • 一块支持 Settings 的开发板，例如 nrf52840dk/nrf52840；

  • 也可使用 qemu_x86 目标。

  • nvs_sector_size 必须小于或等于 0xFFFF。

译校注 · J07-U01

0xFFFF 是哪个后端的上限

这里说的是所核 Settings-NVS 后端的扇区大小，单位为字节：65,535 不因这一项检查被拒，65,536 则超限。满足这个上限不等于满足擦除粒度和分区容量要求，也不能把它推广到其他 Settings 后端。

构建与运行

示例可为多个平台构建。以下命令为 qemu_x86 目标构建应用。

west build -b qemu_x86 samples/subsys/settings
west build -t run

在目标上运行镜像后，控制台将输出各项配置操作的消息。

译校注 · J07-U02

示例日志中的第二处 load

第二处“load all key-value pairs using registered handlers”之后出现导出消息，是因为对应源码打印这行提示后实际调用了 settings_save()。不要据此认为读取配置会自动触发导出。
