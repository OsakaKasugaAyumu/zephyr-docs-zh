CAN 计数器示例（Controller Area Network (CAN) counter）

非官方简体中文译本 · I05 · 英文基线 4.5.99 · 全站目录（94 篇） · I 批目录 · 本页英文原文

在 GitHub 上浏览源码

概述

本例演示 CAN API：在总线上发送带标准和扩展标识符的消息，并通过消息队列和工作队列接收。收到帧后，LED（如有）闪烁，并将接收的计数值打印到控制台。

构建与运行

在环回模式下，板卡会接收自己发出的消息，适合单板测试。

LED 输出引脚由板级设备树定义。

本例既可在 SoC 集成 CAN 控制器的板上运行，也可在另接独立 CAN 控制器的板上构建运行。

集成 CAN 控制器

以 NXP TWR-KE18F 为例：

# From the root of the zephyr repository
west build -b twr_ke18f samples/drivers/can/counter
west flash

独立 CAN 控制器

以下使用 nrf52dk/nrf52832 配合带有 MCP2515 控制器的 DFRobot CAN bus V2.0 扩展板：

# From the root of the zephyr repository
west build -b nrf52dk/nrf52832 --shield dfrobot_can_bus_v2_0 samples/drivers/can/counter
west flash

示例输出

Change LED filter ID: 0
Finished init.
Counter filter id: 4

uart:~$ Counter received: 0
Counter received: 1
Counter received: 2
Counter received: 3

说明

实际显示的数值可能有所不同。
