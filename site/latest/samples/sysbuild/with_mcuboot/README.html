配合 sysbuild 使用 MCUboot

非官方简体中文译本 · 英文基线 4.5.99 · D03 · 全站目录（79 篇） · D 批目录 · 本页英文原文

在 GitHub 上浏览源码

概述

本示例演示如何在使用 sysbuild 构建时自动引入 MCUboot 作为引导程序（bootloader），以及如何通过镜像专用的 Kconfig 片段调整额外镜像的配置。

sysbuild 专用设置

使用 sysbuild 构建此示例时，会自动将 MCUboot 纳入构建，作为引导程序。

这一行为由 sysbuild 专用的 Kconfig 配置文件 sysbuild.conf 实现。

sysbuild 的 Kconfig 文件中，SB_CONFIG_BOOTLOADER_MCUBOOT=y 这项设置会在 sysbuild 构建时启用引导程序。

sysbuild/mcuboot.conf 会作为额外配置片段，与 MCUboot 的默认配置文件合并。

sysbuild/mcuboot.conf 调整 MCUboot 的日志级别，并将 MCUboot 配置为禁止降级，采用只升级（upgrade-only）模式。

要用 west 为 reel_board 同时构建示例和 MCUboot，请运行：

west build -b reel_board --sysbuild samples/sysbuild/with_mcuboot

运行输出：

*** Booting Zephyr OS build v3.2.0-rc3-209-gdcf4201d3573  ***
*** Booting Zephyr OS build v3.2.0-rc3-209-gdcf4201d3573  ***
Address of sample 0xc000
Hello sysbuild with mcuboot! nrf52840dk

第一条 Booting Zephyr OS build 由 MCUboot 本身打印，后续各行由 with_mcuboot 示例打印。该示例还会报告自身在闪存中的位置。
