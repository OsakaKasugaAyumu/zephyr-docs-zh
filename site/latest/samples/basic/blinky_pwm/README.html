PWM 控制 LED 示例（PWM Blinky）

非官方简体中文译本 · H06 · 英文基线 4.5.99 · 全站目录（79 篇） · H 批目录 · 本页英文原文

在 GitHub 上浏览源码

概述

本例通过 PWM API 让 LED 闪烁。基于 GPIO 的版本见 Blinky：LED 闪烁。

LED 从 1 Hz 开始闪烁，每 4 秒频率翻倍，达到 128 Hz 后每 4 秒减半，直到回到 1 Hz。这个先快后慢的循环会一直重复。

并非所有 PWM 硬件都能设置 1 秒周期来实现 1 Hz 闪烁。本例在启动时自动校准，逐步减小最大周期，直到找到硬件支持的值。

硬件要求

开发板须有一个 LED 接到 PWM 输出通道，并通过设备树（Devicetree）别名 pwm_led0 指定控制它的 PWM，通常在 BOARD.dts 文件 中设置。

译校注 · H06-01

DTS 或 overlay 的 aliases 节点中使用 pwm-led0（连字符），C 代码中写作 DT_ALIAS(pwm_led0)（下划线）。这个别名指向描述 PWM LED 的节点，而不是要求 PWM 控制器节点本身叫 pwm_led0。

固定版本依据：Zephyr 1b1b2e0cdca4

main.c：15–18；nucleo_f401re.dts：53–59；nrf52840dk_nrf52840.dts：129–135

如果 pwm_led0 指向已经连到板载 LED 的硬件，则无须额外接线。

构建与运行

为 nRF52840 DK 构建并烧录本例：

west build -b nrf52840dk/nrf52840 samples/basic/blinky_pwm
west flash

对于其他受支持的开发板，请相应替换 nrf52840dk/nrf52840。

烧录后，LED 会按上文描述闪烁，板载控制台也会输出运行信息。
