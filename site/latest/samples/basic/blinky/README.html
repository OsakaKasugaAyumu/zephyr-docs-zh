Blinky：LED 闪烁

非官方简体中文译本 · 英文基线 4.5.99 · B02 · 全站目录（94 篇） · B 批目录 · 本页英文原文

在 GitHub 上浏览源码

概述

Blinky 示例使用 通用输入输出接口（GPIO API） 让 LED 持续闪烁。

源码展示了如何：

  1. 从设备树（Devicetree）中获取引脚描述，并以 gpio_dt_spec 结构表示

  2. 将 GPIO 引脚配置为输出

  3. 持续翻转引脚电平

类似的 PWM 实现见 PWM 闪烁。

硬件要求

开发板必须满足以下条件：

  1. 有一个通过 GPIO 引脚连接的 LED（许多支持的开发板与扩展板将其称为“用户 LED”）。

  2. 在设备树中通过 led0 别名配置该 LED。

构建与运行

按以下步骤构建并烧写 Blinky，将 reel_board 改为你使用的板名：

west build -b reel_board samples/basic/blinky
west flash

烧写后，LED 开始闪烁，控制台会打印 LED 的当前状态。如果发生运行时错误，示例会直接退出，不在控制台打印消息。

构建错误

如果尝试为不受支持的开发板构建 Blinky，在定义变量 struct gpio_dt_spec led 的源码行会出现构建错误。

使用基于 GCC 的工具链时，错误类似于：

error: '__device_dts_ord_DT_N_ALIAS_led_P_gpios_IDX_0_PH_ORD' undeclared here (not in a function)

添加开发板支持

要支持自己的开发板，请在设备树中添加类似以下内容的定义：

/ {
     aliases {
             led0 = &myled0;
     };

     leds {
             compatible = "gpio-leds";
             myled0: led_0 {
                     gpios = <&gpio0 13 GPIO_ACTIVE_LOW>;
             };
     };
};

上述定义将 led0 别名指向 GPIO 控制器 gpio0 上的 13 号引脚。引脚标志 GPIO_ACTIVE_LOW 表示低电平时 LED 亮，高电平时 LED 灭。

提示：

  • 关于如何在设备树中定义由 GPIO 控制的 LED，详见 gpio-leds。

  • 如果不确定如何编写，可以参考采用相同 SoC 且已受支持的板卡设备树。详见查看设备树及生成的头文件。

  • 设备树中可用的标志见 include/zephyr/dt-bindings/gpio/gpio.h。

  • 如果 LED 是板载器件，应在BOARD.dts 文件中定义别名；否则可以在设备树覆盖文件（devicetree overlay）中定义。
