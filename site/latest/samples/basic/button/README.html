按键示例（Button）

非官方简体中文译本 · H03 · 英文基线 4.5.99 · 全站目录（79 篇） · H 批目录 · 本页英文原文

在 GitHub 上浏览源码

概述

本例使用输入 API 处理按键，每按下一次，就在控制台打印一条消息。

硬件要求

开发板必须有能产生 KEY 输入事件的设备节点，通常是通过 GPIO 接入、在 gpio-keys 节点中定义的按键。在许多支持的开发板与扩展板上，这类按键标作「用户按键」。

本例还支持可选的设备树别名 led0。如提供，按下按键时点亮 LED，松开时熄灭。

构建与运行

本例支持多块板，以下以 nucleo_f103rb 为例构建：

west build -b nucleo_f103rb samples/basic/button
