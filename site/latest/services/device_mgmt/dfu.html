设备固件升级（DFU）

非官方简体中文译本 · 英文基线 4.5.99 · D06 · 全站目录（94 篇） · D 批目录 · 本页英文原文

概述

设备固件升级（Device Firmware Upgrade，DFU）子系统提供运行时升级 Zephyr 应用镜像所需的框架。目前它由两个模块组成：

  • subsys/dfu/boot/：与引导程序对接的接口代码；

  • subsys/dfu/img_util/：镜像管理代码。

DFU 子系统管理镜像，但不负责将镜像传到目标设备所需的传输协议或管理协议本身。这些协议及其配套框架见设备管理。

将镜像写入闪存

作为 DFU 子系统的一部分，闪存镜像 API 在 Flash Stream 之上提供抽象，便于将固件镜像分块写入闪存。

MCUboot API

MCUboot API 用于获取应用镜像的版本信息和启动状态，还可选择下次启动使用的应用镜像及启动类型。

引导程序（bootloaders）

MCUboot

Zephyr 直接兼容开源、支持多种实时操作系统的 MCUboot 引导程序，提供与它对接的接口，并支持所需的镜像格式。因此，当 MCUboot 用作 Zephyr 引导程序时，就可以使用设备固件升级功能。MCUboot 源码见MCUboot 的 GitHub 项目。

要将 MCUboot 与 Zephyr 配合使用，请注意：

  1. 需要定义 MCUboot 所需的闪存分区，详见闪存映射（flash map）。

  2. 需要将应用所在的闪存分区指定为选定代码分区（chosen code partition）。

/ {
   chosen {
      zephyr,code-partition = &slot0_partition;
   };
};

  1. 在应用的 .conf 文件中启用 Kconfig 选项 CONFIG_BOOTLOADER_MCUBOOT，使 Zephyr 构建出的应用与 MCUboot 兼容。

  2. 必须构建 MCUboot 本身，并将它烧写到设备上。

  3. 烧写时可能需要采取措施，避免整片擦除闪存；同时要将 Zephyr 应用镜像写入正确偏移，即紧接引导程序之后的位置。

在 Zephyr 中使用 MCUboot 的详细说明，见 MCUboot 网站的搭配 Zephyr 使用 MCUboot页面。
