定长内存池（Memory Slabs）

非官方简体中文译本 · G02 · 英文基线 4.5.99 · 全站目录（79 篇） · G 批目录 · 本页英文原文

定长内存池（memory slab）是内核对象，可从指定内存区域动态分配内存块。池中的块大小相同，因而分配、释放高效，也不必担心不同大小的分配造成碎片。

基本概念

定长内存池数量仅受可用 RAM 限制。每个池通过内存地址引用。

定长内存池的关键属性如下：

  • 每块的块大小，单位为字节。在 32 位平台按 4N 字节取值，在 64 位平台按 8N 字节取值，N 为正整数。

  • 可供分配的块数，必须大于零。

  • 为池中各块提供存储空间的缓冲区，至少需要「块大小 × 块数」字节。

缓冲区须按 N 字节边界对齐，N 为 2 的幂；32 位平台至少为 4，64 位平台至少为 8。为保证每个块都满足同一对齐要求，块大小也必须是 N 的整数倍。

定长内存池须先初始化再使用。初始化将所有块标为空闲。

线程需要内存块时从池中分配；用完必须归还，以便重用。

如果所有块都在使用，线程可选择等待。多个线程可同时等待同一个池；有块可用时，将其交给优先级最高、在相同优先级中等待最久的线程。

可按需定义多个池，例如分别容纳较小和较大的块。另一种做法是使用内存池对象（memory pool）。

内部工作原理

底层缓冲区是定长块数组，块与块之间不浪费空间。

池用链表跟踪空闲块。32 位平台借用每个空闲块的前 4 字节保存链指针，64 位平台使用前 8 字节。

实现

定义定长内存池

用 k_mem_slab 类型定义定长内存池，再通过 k_mem_slab_init() 初始化。

以下池包含 6 个块，每块 400 字节，按 8 字节边界对齐：

struct k_mem_slab my_slab;
char __aligned(8) my_slab_buffer[6 * 400];

k_mem_slab_init(&my_slab, my_slab_buffer, 400, 6);

也可用 K_MEM_SLAB_DEFINE 在编译期定义并初始化内存池。

以下代码效果相同。注意，宏同时定义了池和缓冲区。

K_MEM_SLAB_DEFINE(my_slab, 400, 6, 8);

类似地，也可以在私有作用域中定义定长内存池：

K_MEM_SLAB_DEFINE_STATIC(my_slab, 400, 6, 8);

分配内存块

调用 k_mem_slab_alloc() 分配一个内存块。

以下示例最多等待 100 毫秒。得到块后将其清零；未得到合适的块则打印警告。

char *block_ptr;

if (k_mem_slab_alloc(&my_slab, (void **)&block_ptr, K_MSEC(100)) == 0) {
    memset(block_ptr, 0, 400);
    ...
} else {
    printf("Memory allocation time-out");
}

释放内存块

调用 k_mem_slab_free() 释放一个内存块。

下例分配一个块，在不再需要时释放。

char *block_ptr;

k_mem_slab_alloc(&my_slab, (void **)&block_ptr, K_FOREVER);
... /* use memory block pointed at by block_ptr */
k_mem_slab_free(&my_slab, (void *)block_ptr);

查询内存池使用情况

运行时可查询池的利用情况。k_mem_slab_num_used_get() 返回已分配的块数，k_mem_slab_num_free_get() 返回剩余可用块数。启用 CONFIG_MEM_SLAB_TRACE_MAX_UTILIZATION 后，k_mem_slab_max_used_get() 还会报告同时被占用的块数峰值，k_mem_slab_runtime_stats_get() 可将这些统计值汇集到一个 sys_memory_stats 结构中。

建议用法

以固定大小为单位分配和释放内存时，可使用定长内存池。

线程间传送大量数据时，可传递池中的内存块，避免不必要的数据复制。
