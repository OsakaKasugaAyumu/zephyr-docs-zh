内存块分配器（Memory Blocks Allocator）

非官方简体中文译本 · G03 · 英文基线 4.5.99 · 全站目录（79 篇） · G 批目录 · 本页英文原文

内存块分配器（Memory Blocks Allocator）可从指定区域动态分配内存块，具有如下特点：

  • 所有块的大小相同。

  • 可一次分配或释放多个块。

  • 一起分配的块不保证地址连续，适用于分散／聚集（scatter-gather）DMA 等操作。

  • 与定长内存池不同，分配记录存放在缓冲区外，因此缓冲区所在的存储区域可以断电以节省能耗。

基本概念

分配器数量仅受可用 RAM 限制，每个分配器通过内存地址引用。

内存块分配器的关键属性如下：

  • 每块的块大小，以字节计，按 4N 字节取值，N 为正整数。

  • 可供分配的块数，必须大于零。

  • 缓冲区提供实际存储空间，至少需要「块大小 × 块数」字节。

  • 块位图（blocks bitmap）记录哪些块已经分配。

缓冲区须按 N 字节边界对齐，N 为大于 2 的 2 的幂（4、8、16 等）。块大小也须为 N 的倍数，使每块均满足对齐要求。

由于内部管理结构的创建方式，每个分配器都必须在编译期声明并定义。

内部工作原理

每个分配器的缓冲区都是定长块数组，块之间没有浪费的空间。

分配器用位图跟踪空闲块。

内存块分配器（Memory Blocks Allocator）

实现使用位图标记已分配块。分配器通过 sys_bitarray 接口从后备缓冲区逐个取得块，直到达到请求数量。所有元数据均在缓冲区之外；分配器代码不访问缓冲区内容，因此可让该区域断电以节能。

多内存块分配器组

分配器组的工具函数便于统一管理多个分配器。可以编写自定义选择函数，决定本次请求使用组中的哪个分配器。

运行时用 sys_multi_mem_blocks_init() 初始化组，再用 sys_multi_mem_blocks_add_allocator() 逐个加入分配器。

通过 sys_multi_mem_blocks_alloc() 从组中分配时，传入一个由调用方解释的配置参数。它会原样交给选择函数，用来选择合适的分配器，再通过 sys_mem_blocks_alloc() 分配块。

用 sys_multi_mem_blocks_free() 释放时，不必传入配置参数。实现根据传入的内存地址找到对应的分配器，再调用 sys_mem_blocks_free() 释放块。

用法

定义内存块分配器

用 sys_mem_blocks_t 类型表示内存块分配器。必须通过 SYS_MEM_BLOCKS_DEFINE 在编译期完成定义和初始化。

以下分配器有 4 个块，每块 64 字节，按 4 字节边界对齐：

SYS_MEM_BLOCKS_DEFINE(allocator, 64, 4, 4);

也可在私有作用域定义分配器：

SYS_MEM_BLOCKS_DEFINE_STATIC(static_allocator, 64, 4, 4);

也可将预先定义的缓冲区交给分配器，以便单独放置缓冲区。注意：定义缓冲区时必须指定其对齐要求。

uint8_t __aligned(4) backing_buffer[64 * 4];
SYS_MEM_BLOCKS_DEFINE_WITH_EXT_BUF(allocator, 64, 4, backing_buffer);

分配内存块

调用 sys_mem_blocks_alloc() 分配内存块。

int ret;
uintptr_t blocks[2];

ret = sys_mem_blocks_alloc(allocator, 2, blocks);

若 ret == 0，数组 blocks 中保存的是所分配内存块的地址。

释放内存块

调用 sys_mem_blocks_free() 释放内存块。

下例分配两个块，不再需要时将它们释放。

int ret;
uintptr_t blocks[2];

ret = sys_mem_blocks_alloc(allocator, 2, blocks);
... /* perform some operations on the allocated memory blocks */
ret = sys_mem_blocks_free(allocator, 2, blocks);

使用多内存块分配器组

以下代码展示如何初始化分配器组：

sys_mem_blocks_t *choice_fn(struct sys_multi_mem_blocks *group, void *cfg)
{
    ... /* choose which allocator in the group to use based on cfg */
}

SYS_MEM_BLOCKS_DEFINE(allocator0, 64, 4, 4);
SYS_MEM_BLOCKS_DEFINE(allocator1, 64, 4, 4);

static sys_multi_mem_blocks_t alloc_group;

sys_multi_mem_blocks_init(&alloc_group, choice_fn);
sys_multi_mem_blocks_add_allocator(&alloc_group, &allocator0);
sys_multi_mem_blocks_add_allocator(&alloc_group, &allocator1);

从组中分配以及向组归还内存块：

int ret;
uintptr_t blocks[1];
size_t blk_size;

ret = sys_multi_mem_blocks_alloc(&alloc_group, UINT_TO_POINTER(0),
                                 1, blocks, &blk_size);

ret = sys_multi_mem_blocks_free(&alloc_group, 1, blocks);
