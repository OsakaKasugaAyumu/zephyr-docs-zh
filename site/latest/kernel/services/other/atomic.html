原子操作（Atomic Services）

非官方简体中文译本 · F01 · 英文基线 4.5.99 · 全站目录（79 篇） · F 批目录 · 本页英文原文

线程和中断服务程序（ISR）对原子变量（atomic variable）的读改操作不可分割。它在 32 位机器上占 32 位，在 64 位机器上占 64 位。

基本概念

原子变量的数量仅受可用 RAM 限制。

用内核的原子 API 操作变量时，即使更高优先级的执行上下文也在操作同一个变量，所请求的操作仍能正确完成。

内核还支持原子地操作原子变量数组中的某一位。

实现

定义原子变量

使用 atomic_t 类型定义原子变量。

原子变量默认初始化为零。要指定其他初值，可使用 ATOMIC_INIT：

atomic_t flags = ATOMIC_INIT(0xFF);

操作原子变量

本节末尾列出了用于操作原子变量的 API。

下面用原子变量统计函数调用次数。由于递增操作不可分割，即使调用函数的线程被更高优先级的上下文打断，而后者又调用了同一函数，计数也不会在递增过程中损坏。

atomic_t call_count;

int call_counting_routine(void)
{
    /* increment invocation counter */
    atomic_inc(&call_count);

    /* do rest of routine's processing */
    ...
}

操作原子变量数组

可以用常规方式定义由 32 位原子变量组成的数组，也可以用 ATOMIC_DEFINE 定义含 N 个比特的原子位数组。

要操作数组中的单个位，可使用本节末尾列出的以 _bit() 结尾的 API。

下面用原子变量数组实现 200 个标志位。

#define NUM_FLAG_BITS 200

ATOMIC_DEFINE(flag_bits, NUM_FLAG_BITS);

/* set specified flag bit & return its previous value */
int set_flag_bit(int bit_position)
{
    return (int)atomic_set_bit(flag_bits, bit_position);
}

内存顺序（memory ordering）

为了保证一致性和正确性，所有 Zephyr 原子 API 都应在硬件需要时提供完整内存屏障（例如 x86 的串行化指令、ARM 的 DMB，或 C++ 内存模型中的顺序一致操作），使不同上下文对内存具有一致可靠的视图。各架构的实现负责保证这一行为。

建议用法

临界区若只涉及一个 32 位值，可使用原子变量。

对长度超过 32 位的位数组，可用多个原子变量处理临界区内的标志位。

说明

与互斥锁或屏蔽中断等临界区保护方法相比，原子变量通常高效得多。

配置选项

相关配置选项：

  • CONFIG_ATOMIC_OPERATIONS_BUILTIN

  • CONFIG_ATOMIC_OPERATIONS_ARCH

  • CONFIG_ATOMIC_OPERATIONS_C
