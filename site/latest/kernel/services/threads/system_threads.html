系统线程

系统线程（system thread）是内核在系统初始化期间自动创建的线程。

内核会创建以下系统线程：

主线程（main thread）

主线程执行内核初始化，然后调用应用的 main() 函数（如果已定义）。

默认使用已配置的最高可抢占优先级（即 0）。若内核未配置可抢占线程，主线程使用最低协作式优先级（即 −1）。

主线程在初始化内核和执行应用的 main() 期间属于关键线程；若被强制中止，会触发致命系统错误。若没有定义 main()，或者该函数执行后正常返回，主线程会正常终止，不会报错。

空闲线程（idle thread）

系统无其他工作时由空闲线程执行。条件允许时，它启用开发板的电源管理功能来节能；否则执行空循环。系统只要还在运行，空闲线程就一直存在，不会终止。

空闲线程始终使用已配置的最低线程优先级。

空闲线程是关键线程；如果它被强制中止，会触发致命系统错误。

根据应用指定的内核和板级配置，还可能创建其他系统线程。例如，启用系统工作队列时会创建线程，用来处理提交给该队列的工作项。（见工作队列线程。）

实现

编写 main() 函数

内核初始化完成后，才开始执行应用提供的 main()。默认不向它传递参数；若选择 CONFIG_BOOTARGS，内核就会传参，可采用 main(int, char **) 形式。

下面是一个简单的 main(void) 示例。实际应用可按需实现更复杂的功能。

int main(void)
{
    /* initialize a semaphore */
    ...

    /* register an ISR that gives the semaphore */
    ...

    /* monitor the semaphore forever */
    while (1) {
        /* wait for the semaphore to be given by the ISR */
        ...
        /* do whatever processing is now needed */
        ...
    }
}

建议用法

如果应用只需一个线程，可直接使用主线程处理任务，无需额外定义应用专用线程。
