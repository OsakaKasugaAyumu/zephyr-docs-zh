事件（Events）

非官方简体中文译本 · E08 · 英文基线 4.5.99 · 全站目录（79 篇） · E 批目录 · 本页英文原文

事件对象（event object）是实现传统事件通知语义的内核对象。

基本概念

可以定义任意数量的事件对象，只受可用 RAM 限制；每个对象通过内存地址引用。一个或多个线程可以在同一对象上等待所需的事件集合。新事件到达时，所有满足等待条件的线程会同时就绪。

事件对象有以下关键属性：

  • 一个 32 位值，记录已送达该对象的事件。

事件对象必须先初始化才能使用。

线程和 ISR 均可发送事件。有两种方式：覆盖现有事件集合称为设置（set）；按位将新事件加入原集合称为发布（post）。两种操作都可能同时满足多个等待线程的条件；所有条件得到满足的线程都会同时就绪。

线程可等待一个或多个事件，可要求全部发生，也可接受任意一个。发起等待时，还可选择在等待之前清除对象当前记录的事件。若多个线程等待同一对象，使用此选项须谨慎。

说明

ISR 可以查询事件对象，但不得尝试等待事件。

实现

定义事件对象

用 k_event 类型的变量定义事件对象，再调用 k_event_init() 初始化。

下例定义一个事件对象。

struct k_event my_event;

k_event_init(&my_event);

也可用 K_EVENT_DEFINE 在编译时定义并初始化事件对象。

以下代码与上面的代码片段效果相同。

K_EVENT_DEFINE(my_event);

设置事件

调用 k_event_set() 设置对象中的事件位。

延续上例，将对象跟踪的事件集合设为 0x001。

void input_available_interrupt_handler(void *arg)
{
    /* notify threads that data is available */

    k_event_set(&my_event, 0x001);

    ...
}

发布事件

调用 k_event_post() 发布事件，将新事件位加入原集合。

延续上例，向事件对象发布一组事件。

void input_available_interrupt_handler(void *arg)
{
    ...

    /* notify threads that more data is available */

    k_event_post(&my_event, 0x120);

    ...
}

等待事件（不移除）

线程调用 k_event_wait() 等待事件。

延续上例，最多等待 50 毫秒，只要指定事件中的任意一个被发布即可。如果都未及时发生，则发出警告。

void consumer_thread(void)
{
    uint32_t  events;

    events = k_event_wait(&my_event, 0xFFF, false, K_MSEC(50));
    if (events == 0) {
        printk("No input devices are available!");
    } else {
        /* Access the desired input device(s) */
        ...
    }
    ...
}

消费者若需等待全部指定事件再继续，可改用 k_event_wait_all()。

void consumer_thread(void)
{
    uint32_t  events;

    events = k_event_wait_all(&my_event, 0x121, false, K_MSEC(50));
    if (events == 0) {
        printk("At least one input device is not available!");
    } else {
        /* Access the desired input devices */
        ...
    }
    ...
}

等待事件（接收时移除）

线程可调用 k_event_wait_safe() 等待事件，同时在收到时以原子方式移除匹配的事件位。

延续上例，最多等待 50 毫秒，只要指定事件中的任意一个被发布即可。如果都未及时发生，则发出警告。

若及时收到事件，对应事件位将不再出现在对象中，直到下次被设置或发布。

void consumer_thread(void)
{
    uint32_t  events;

    events = k_event_wait_safe(&my_event, 0xFFF, false, K_MSEC(50));
    if (events == 0) {
        printk("No input devices are available!");
    } else {
        /* Access the desired input device(s) */
        ...
    }
    ...
}

如果要等到全部事件并在收到时原子移除，然后继续执行，可改用 k_event_wait_all_safe()。

若及时收到全部事件，对应事件位将从对象中消失，直到下次被设置或发布。

void consumer_thread(void)
{
    uint32_t  events;

    events = k_event_wait_all_safe(&my_event, 0x121, false, K_MSEC(50));
    if (events == 0) {
        printk("At least one input device is not available!");
    } else {
        /* Access the desired input devices */
        ...
    }
    ...
}

建议用法

用事件表示一组条件已经发生。

用事件一次向多个线程传递少量数据。
