信号量（Semaphores）

非官方简体中文译本 · E06 · 英文基线 4.5.99 · 全站目录（94 篇） · E 批目录 · 本页英文原文

信号量（semaphore）是实现传统计数信号量语义的内核对象。

基本概念

可以定义任意数量的信号量，只受可用 RAM 限制。每个信号量通过其内存地址引用。

信号量有以下关键属性：

  • 计数（count）表示信号量还可被成功获取多少次。计数为零表示它当前不可用。

  • 上限（limit）规定计数的最大值。

使用前必须初始化信号量。计数须为非负值，且不能超过上限。

线程或 ISR 均可释放信号量。每释放一次，计数加一；若已达上限，计数不变。

线程可以获取信号量。如果计数不为零，获取会将计数减一。计数为零时，线程可选择等待他人释放。可以同时有任意数量的线程等待；释放后，在最高优先级的等待线程中，由等待最久者取得信号量。

说明

将信号量初始化为“满”（计数等于上限），可以限制同时进入临界区的线程数。也可初始化为“空”（计数为零且上限大于零），相当于一道门：计数增加之前，等待线程均不能通过。常见的标准信号量用法都受支持。

说明

内核允许 ISR 获取信号量，但若信号量不可用，ISR 不得尝试等待。

实现

定义信号量

用 k_sem 类型的变量定义信号量，再调用 k_sem_init() 初始化。

下例定义一个信号量，将初始计数设为 0、上限设为 1，得到二值信号量。

struct k_sem my_sem;

k_sem_init(&my_sem, 0, 1);

也可用 K_SEM_DEFINE 在编译时定义并初始化信号量。

以下代码与上面的代码片段效果相同。

K_SEM_DEFINE(my_sem, 0, 1);

释放信号量

调用 k_sem_give() 释放信号量。

延续上例，通过释放信号量通知消费者线程：有一份数据可以处理。

void input_data_interrupt_handler(void *arg)
{
    /* notify thread that data is available */
    k_sem_give(&my_sem);

    ...
}

获取信号量

调用 k_sem_take() 获取信号量。

延续上例，最多等待 50 毫秒。如果未能及时获取信号量，则发出警告。

void consumer_thread(void)
{
    ...

    if (k_sem_take(&my_sem, K_MSEC(50)) != 0) {
        printk("Input data not available!");
    } else {
        /* fetch available data */
        ...
    }
    ...
}

建议用法

使用信号量控制多个线程对一组资源的访问。

使用信号量同步生产者和消费者的处理过程，它们可以是线程或 ISR。
