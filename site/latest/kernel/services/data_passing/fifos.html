先进先出队列（FIFOs）

非官方简体中文译本 · F06 · 英文基线 4.5.99 · 全站目录（79 篇） · F 批目录 · 本页英文原文

FIFO是实现先进先出队列的内核对象，允许线程和 ISR 加入或取出任意大小的数据项。

基本概念

FIFO 的数量仅受可用 RAM 限制，每个 FIFO 通过内存地址引用。

FIFO 的关键属性如下：

  • 已加入但尚未取出数据项的队列。底层由简单链表实现。

FIFO 必须先初始化再使用，初始队列为空。

FIFO 数据项必须按指针对齐，因为内核占用首个指针大小的字段，指向队列中的下一项。因此，N 字节的应用数据需占 N+4（或 N+8）字节。若通过 k_fifo_alloc_put() 加入，则无上述对齐和预留空间要求；内核会从调用线程的资源池临时分配额外内存。

说明

同一数据项在所有 FIFO 中同时只能有一个有效实例。在它从原队列取出前再次入队，会造成未定义行为。

线程或 ISR 均可将数据项加入到 FIFO。若已有线程等待，则直接交给它；否则加入队列。排队的数据项数没有硬性上限。

线程可从 FIFO 取出数据项。若队列为空，可选择等待；多个线程可同时等待。新项交给优先级最高且在同优先级中等待最久的线程。

说明

ISR 可以从 FIFO 取数据，但队列为空时绝不能等待。

若多个数据项已经串成单向链表，可在一次操作中把整串加入 FIFO。多个写入者提交相关数据时，可保证同组的项不会和其他项交错。批量加入也比逐项加入高效，并可保证取到组内第一项时，其余各项已入队，无须等待其到达。

实现

定义 FIFO

用 k_fifo 类型定义 FIFO，再调用 k_fifo_init() 初始化。

以下代码定义并初始化一个空 FIFO。

struct k_fifo my_fifo;

k_fifo_init(&my_fifo);

也可调用 K_FIFO_DEFINE 在编译期定义并初始化空 FIFO。

以下代码与上面的代码片段效果相同。

K_FIFO_DEFINE(my_fifo);

写入 FIFO

调用 k_fifo_put() 向 FIFO 加入一个数据项。

以下示例接续上例，用 FIFO 向一个或多个消费线程发送数据。

struct data_item_t {
    void *fifo_reserved;   /* 1st word reserved for use by FIFO */
    ...
};

struct data_item_t tx_data;

void producer_thread(int unused1, int unused2, int unused3)
{
    while (1) {
        /* create data item to send */
        tx_data = ...

        /* send data to consumers */
        k_fifo_put(&my_fifo, &tx_data);

        ...
    }
}

还可调用 k_fifo_put_list() 或 k_fifo_put_slist()，一次向 FIFO 加入由单向链表串起的多个数据项。

也可用 k_fifo_alloc_put() 加入数据项，不必为内核预留字段；内核会从调用线程的资源池分配额外内存，直到该项被读取。

从 FIFO 读取

调用 k_fifo_get() 从 FIFO 取出一个数据项。

以下代码接续上例，通过 FIFO 获取生产线程送来的数据项，再作处理。

void consumer_thread(int unused1, int unused2, int unused3)
{
    struct data_item_t  *rx_data;

    while (1) {
        rx_data = k_fifo_get(&my_fifo, K_FOREVER);

        /* process FIFO data item */
        ...
    }
}

建议用法

使用 FIFO 可按先进先出顺序异步传递任意大小的数据项。
