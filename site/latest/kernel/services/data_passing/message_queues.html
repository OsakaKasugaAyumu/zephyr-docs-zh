消息队列（Message Queues）

非官方简体中文译本 · E09 · 英文基线 4.5.99 · 全站目录（94 篇） · E 批目录 · 本页英文原文

消息队列（message queue）是实现简单消息队列的内核对象，线程和 ISR 可通过它异步收发固定大小的数据项。

基本概念

可以定义任意数量的消息队列，只受可用 RAM 限制。每个队列通过内存地址引用。

消息队列有以下关键属性：

  • 一个环形缓冲区（ring buffer），存放已发送但尚未被接收的数据项。

  • 数据项大小，以字节为单位。

  • 环形缓冲区中可排入数据项的最大数量。

须先初始化消息队列才能使用。初始化会清空环形缓冲区。

线程或 ISR 可将数据项发送到队列。若有线程正在等待接收，会直接将发送方指向的数据复制给等待者；否则，在缓冲区有空间时将其复制到缓冲区中。两种情况下，发送数据区的大小都必须等于队列设定的数据项大小。

如果环形缓冲区已满，发送线程可选择等待空位。任意数量的发送线程可同时等待；有空位时，由优先级最高且已等待最久的发送线程获得。

线程可从队列接收数据项。数据被复制到接收方指定的区域，区域大小必须等于队列设定的数据项大小。

如果环形缓冲区为空，接收线程可选择等待数据到来。任意数量的接收线程可同时等待；有数据时，交给优先级最高且等待最久的接收线程。

线程也可查看（peek）队首消息而不将其移出队列。数据会复制到接收方指定的区域，区域大小必须等于队列设定的数据项大小。

说明

ISR 可以从消息队列接收数据项；但队列为空时，ISR 不得尝试等待。

说明

环形缓冲区本身不要求对齐。底层使用不依赖地址对齐的 memcpy()，并且不向外部暴露任何内部指针。

实现

定义消息队列

用 k_msgq 类型的变量定义消息队列，再调用 k_msgq_init() 初始化。

下例定义并初始化一个空消息队列，最多容纳 10 个数据项，每项 12 字节。

struct data_item_type {
    uint32_t field1;
    uint32_t field2;
    uint32_t field3;
};

char my_msgq_buffer[10 * sizeof(struct data_item_type)];
struct k_msgq my_msgq;

k_msgq_init(&my_msgq, my_msgq_buffer, sizeof(struct data_item_type), 10);

也可使用以下任一宏在编译时定义并初始化消息队列：

  • K_MSGQ_DEFINE：定义公开的消息队列。

  • K_MSGQ_DEFINE_STATIC：定义私有消息队列（静态作用域）。

  • K_MSGQ_DEFINE_TYPE：为指定的数据项类型定义公开的消息队列。

  • K_MSGQ_DEFINE_STATIC_TYPE：为指定的数据项类型定义私有消息队列。

下列代码与上段等效。注意，该宏会同时定义消息队列和缓冲区。

K_MSGQ_DEFINE(my_msgq, sizeof(struct data_item_type), 10, 1);

若编译时已知队列的数据项类型，可使用简写宏 K_MSGQ_DEFINE_TYPE，自动配置数据项大小与对齐：

K_MSGQ_DEFINE_TYPE(my_msgq, struct data_item_type, 10);

写入消息队列

调用 k_msgq_put() 向消息队列加入一个数据项。

延续上例，生产者线程通过消息队列向一个或多个消费者线程发送数据。若消费者跟不上，队列变满，示例中的生产者会丢弃所有旧数据以保留较新的数据。注意，该 API 会触发重新调度。

void producer_thread(void)
{
    struct data_item_type data;

    while (1) {
        /* create data item to send (e.g. measurement, timestamp, ...) */
        data = ...

        /* send data to consumers */
        while (k_msgq_put(&my_msgq, &data, K_NO_WAIT) != 0) {
            /* message queue is full: purge old data & try again */
            k_msgq_purge(&my_msgq);
        }

        /* data item was successfully added to message queue */
    }
}

读取消息队列

调用 k_msgq_get() 从消息队列取出一个数据项。

延续上例，处理一个或多个生产者生成的数据。应检查 k_msgq_get() 的返回值，因为调用 k_msgq_purge() 可能导致它返回 -ENOMSG。

void consumer_thread(void)
{
    struct data_item_type data;

    while (1) {
        /* get a data item */
        k_msgq_get(&my_msgq, &data, K_FOREVER);

        /* process data item */
        ...
    }
}

查看队首而不出队

调用 k_msgq_peek() 读取队首数据但不将其移除。

下例查看队首，读取由一个或多个生产者生成的数据项，而不将其出队。

void consumer_thread(void)
{
    struct data_item_type data;

    while (1) {
        /* read a data item by peeking into the queue */
        k_msgq_peek(&my_msgq, &data);

        /* process data item */
        ...
    }
}

建议用法

用消息队列在线程之间异步传递小数据项。

说明

也可用消息队列传输大数据项，但可能增大中断延迟：读写数据项期间会锁定中断，每次都要在内存中复制整个数据项，所需时间随数据项大小线性增长。因此，对大数据通常应传递指向数据的指针，而不是复制数据本身。

如需同步传输，可使用内核邮箱（mailbox）对象。
