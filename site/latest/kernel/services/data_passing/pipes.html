管道（Pipes）

非官方简体中文译本 · F08 · 英文基线 4.5.99 · 全站目录（94 篇） · F 批目录 · 本页英文原文

管道（pipe）是用来在线程之间发送字节流的内核对象，可高效地在线程间通信，并以同步方式传输整个数据块或其中一部分。

基本概念

管道数量仅受可用 RAM 限制，每个管道通过其内存地址引用。

管道有以下关键属性：

  • 大小指定管道环形缓冲区的容量。大小为零表示没有环形缓冲区。

管道必须先初始化再使用，初始状态为空。

线程与管道的交互如下：

  • 写入：线程同步写入全部或部分数据。已接收的数据要么直接复制给等待的读取者，要么复制到管道的环形缓冲区。如果缓冲区已满或根本没有缓冲区，操作将阻塞，直到有足够空间或指定的等待时间到期。

  • 读取：线程同步读取全部或部分数据。数据要么来自管道的环形缓冲区，要么直接来自等待的发送者。如果缓冲区为空或根本没有缓冲区，操作将阻塞，直到有数据可读或超时。

  • 重置：线程可以重置管道，清除内部状态，使所有正在等待的读写操作以错误码结束。

管道适用于生产者／消费者模式，以及在线程间传输连续数据流等场景。

实现

用一个 k_pipe 类型的变量和一个字节缓冲区定义管道，再调用 k_pipe_init() 初始化。

以下代码定义并初始化一个空管道，其环形缓冲区可容纳 100 字节，并按 4 字节边界对齐：

uint8_t __aligned(4) my_ring_buffer[100];
struct k_pipe my_pipe;

k_pipe_init(&my_pipe, my_ring_buffer, sizeof(my_ring_buffer));

也可在编译期用 K_PIPE_DEFINE 同时定义管道和环形缓冲区并完成初始化：

K_PIPE_DEFINE(my_pipe, 100, 4);

效果与上例相同。

不使用环形缓冲区时，缓冲区指针应为 NULL，大小应为 0。

写入管道

调用 k_pipe_write() 向管道写入数据。

下例通过管道把生产线程的数据发给一个或多个消费线程。若管道的环形缓冲区已满，生产线程最多等待指定的时间。

struct message_header {
    size_t num_data_bytes; /* Example field */
    ...
};

void producer_thread(void)
{
    int rc;
    uint8_t *data;
    size_t total_size;
    size_t bytes_written;

    while (1) {
        /* Craft message to send in the pipe */
        make_message(data, &total_size);
        bytes_written = 0;

        /* Write data to the pipe, handling partial writes */
        while (bytes_written < total_size) {
            rc = k_pipe_write(&my_pipe, &data[bytes_written], total_size - bytes_written, K_NO_WAIT);

            if (rc < 0) {
                /* Error occurred */
                ...
                break;
            } else {
                /* Partial or full write succeeded; adjust for next iteration */
                bytes_written += rc;
            }
        }

        /* Reset bytes_written for the next message */
        bytes_written = 0;
        ...
    }
}

读取管道

调用 k_pipe_read() 从管道读取数据。

下例接续上面的生产线程示例，展示消费线程如何处理生产者生成的数据。

struct message_header {
    size_t num_data_bytes; /* Example field */
    ...
};

void consumer_thread(void)
{
    int rc;
    uint8_t buffer[128];
    size_t bytes_read = 0;
    struct message_header *header = (struct message_header *)buffer;

    while (1) {
        /* Step 1: Read the message header */
        bytes_read = 0;
   read_header:
        while (bytes_read < sizeof(*header)) {
            rc = k_pipe_read(&my_pipe, &buffer[bytes_read], sizeof(*header) - bytes_read, &bytes_read, K_NO_WAIT);

            if (rc < 0) {
                /* Error occurred */
                ...
                goto read_header;
            }

            /* Adjust for partial reads */
            bytes_read += rc;
        }

        /* Step 2: Read the message body */
        bytes_read = 0;
        while (bytes_read < header->num_data_bytes) {
            rc = k_pipe_read(&my_pipe, &buffer[sizeof(*header) + bytes_read], header->num_data_bytes - bytes_read, K_NO_WAIT);

            if (rc < 0) {
                /* Error occurred */
                ...
                goto read_header;
            }

            /* Adjust for partial reads */
            bytes_read += rc;
        }
        /* Successfully received the complete message */
    }
}

重置管道

调用 k_pipe_reset() 可重置管道。这会重置其内部状态，使所有正在等待的操作以错误码结束。

下例演示发生严重错误时如何重置管道：

void monitor_thread(void)
{
    while (1) {
        ...
        /* Critical error detected: reset the entire pipe to reset it. */
        k_pipe_reset(&my_pipe);
        ...
    }
}

建议用法

管道适合在线程间传输字节流，典型用途包括：

  • 实现生产者／消费者模式。

  • 在线程间连续传输日志或数据包。

  • 在实时系统中传递变长消息。
