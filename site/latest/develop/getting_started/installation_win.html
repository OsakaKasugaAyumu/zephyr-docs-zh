Windows 的其他配置方式

非官方简体中文译本 · 英文基线 4.5.99 · A04 · 全站目录（94 篇） · A 批目录 · 本页英文原文

Windows 10 的 Linux 子系统（Windows Subsystem for Linux，WSL）

如果使用较新版本的 Windows 10，可以借助内置功能，直接从标准命令提示符原生运行 Ubuntu 二进制程序，这样无需配置虚拟机即可使用 Zephyr SDK 等软件。

警告

Windows 10 1803 版有一个会使 CMake 无法正常工作的问题，该问题已在 1809 及后续版本中修复。详见 Zephyr 议题 10420。

  1. 安装适用于 Linux 的 Windows 子系统（WSL）.

    说明

    要使 Zephyr SDK 正常工作，Windows 10 构建号必须为 15002 或更高。可在系统设置的“关于你的电脑”中查看当前构建号。若使用更早的构建，可能需要安装“创意者更新”（Creators Update）。

  2. 按照安装 Linux 主机依赖项中的 Ubuntu 步骤操作。
