入门指南（Getting Started Guide）

非官方简体中文译本 · 英文基线 4.5.99 · P01 · 全站目录（79 篇） · 本页英文原文
标有「英」的链接前往英文文档；命令、路径与版本号按原文保留。

按照本指南，你可以：

  • 在 Ubuntu、macOS 或 Windows 上搭建 Zephyr 命令行开发环境（其他 Linux 发行版请参阅安装 Linux 主机依赖项）；

  • 获取源代码；

  • 构建（build）、烧写（flash）并运行一个示例应用。

选择并更新操作系统

请选择你正在使用的操作系统。

本指南适用于 Ubuntu 24.04 LTS 及更高版本。如果使用其他 Linux 发行版，请参阅安装 Linux 主机依赖项。

sudo apt update
sudo apt upgrade

依次打开系统设置 ‣ 通用 ‣ 软件更新，安装所有可用更新。详情见Apple 的这篇支持文章。

说明

不支持 x86-64 版 macOS。

依次打开开始 ‣ 设置 ‣ 更新和安全 ‣ Windows 更新。点击检查更新，安装所有可用更新。

安装依赖项

接下来安装主机工具（host tools），Zephyr 用它们配置和构建应用。下文采用各操作系统推荐的软件包管理器，安装后即可从终端调用这些工具。

主要依赖项的最低版本要求如下：

工具

最低版本

CMake

3.28.0

Python

3.12

设备树编译器（Devicetree compiler）

1.4.6

说明

强烈建议使用 Python 3.12。使用更新的 Python 版本在某些系统上可能会失败，例如在 Windows 上安装所需的软件包时。

  1. 使用 apt 安装所需的依赖项：

    sudo apt install --no-install-recommends git cmake ninja-build gperf \
  ccache dfu-util device-tree-compiler wget python3-dev python3-venv python3-tk \
  xz-utils file make gcc gcc-multilib g++-multilib libsdl2-dev libmagic1

    说明

    AArch64（ARM64）系统上没有 gcc-multilib 和 g++-multilib，可能需要从待安装的软件包列表中去掉这两项。

  2. 输入以下命令，检查系统中已安装的主要依赖项版本：

    cmake --version
python3 --version
dtc --version

    将结果与本节开头表格中的最低版本对照。如需手动更新依赖项，请参阅安装 Linux 主机依赖项。

  1. 安装 Homebrew：

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

  2. Homebrew 安装脚本运行结束后，按屏幕提示将 Homebrew 的安装路径加入命令搜索路径。

    (echo; echo 'eval "$(/opt/homebrew/bin/brew shellenv)"') >> ~/.zprofile
source ~/.zprofile

  3. 使用 brew 安装所需的依赖项：

    brew install cmake ninja gperf python3 python-tk ccache qemu dtc libmagic wget openocd

  4. 将 Homebrew 的 Python 目录加入命令搜索路径，这样除了 python3 和 pip3，也可以直接运行 python 和 pip。

    (echo; echo 'export PATH="'$(brew --prefix)'/opt/python/libexec/bin:$PATH"') >> ~/.zprofile
source ~/.zprofile

说明

以下说明适用于原生 Windows 环境。你也可以使用适用于 Linux 的 Windows 子系统（WSL），改按本指南中的 Ubuntu 步骤操作。请注意：要在 WSL 内烧写和调试硬件，必须先让 WSL 能够访问 USB 设备，例如使用 usbipd-win。

在 Windows 10 及更高版本上，从 Microsoft Store 安装 Windows 终端（Windows Terminal）。以下命令既可在 cmd.exe 中运行，也可在 PowerShell 中运行。

本指南使用 Windows 官方软件包管理器 winget。如果不能使用 winget，请从各依赖项的官网下载，并确保其命令行工具所在目录已加入 PATH 环境变量。

  1. 新版 Windows 默认已预装 winget。在终端输入 winget 即可检查；若命令运行失败，可按说明安装 winget。

  2. 打开命令提示符（cmd.exe）或 PowerShell 终端窗口：按 Windows 键，输入 cmd.exe 或 PowerShell，然后点击搜索结果。

  3. 使用 winget 安装所需的依赖项：

    winget install Kitware.CMake Ninja-build.Ninja oss-winget.gperf Python.Python.3.12 Git.Git oss-winget.dtc wget 7zip.7zip

  4. 关闭终端窗口。

说明

你可能需要将 7zip 安装目录加入 PATH。

获取 Zephyr 并安装 Python 依赖项

接下来使用 west 创建工作区（workspace），获取 Zephyr 及其模块（modules）。

以下命令使用 zephyrproject 作为工作区名称；你也可以选择其他名称和位置。Zephyr 的 Python 依赖项将安装在Python 虚拟环境（virtual environment）中，与系统的 Python 环境隔离。

  1. 创建一个新的虚拟环境：

    python3 -m venv ~/zephyrproject/.venv

    python3 -m venv ~/zephyrproject/.venv

    以普通用户身份打开 cmd.exe 或 PowerShell 终端窗口。

    cd %HOMEPATH%
py -3.12 -m venv zephyrproject\.venv

    cd $Env:HOMEPATH
py -3.12 -m venv zephyrproject\.venv

  2. 激活虚拟环境：

    source ~/zephyrproject/.venv/bin/activate

    source ~/zephyrproject/.venv/bin/activate

    说明

    在 PowerShell 中激活 Python 虚拟环境本身也需要运行脚本，因此必须允许执行该脚本。

    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

    zephyrproject\.venv\Scripts\activate.bat

    zephyrproject\.venv\Scripts\Activate.ps1

    激活后，命令提示符前会出现 (.venv)。随时都可以运行 deactivate 退出虚拟环境。

    说明

    每次打开新的终端会话，在开始使用 Zephyr 前，都要先激活虚拟环境。否则，终端可能找不到 west 等命令，或者会在另一个 Python 环境中运行它们，导致难以排查的错误。

  3. 安装 west：

    west 是 Zephyr 的工作区管理工具；接下来的命令用它来创建和更新工作区。

    pip install west

  4. 获取 Zephyr 源代码：

    west init 会创建一个 west 工作区，并克隆 https://github.com/zephyrproject-rtos/zephyr 作为清单仓库（manifest repository）。

    随后，west update 会获取 Zephyr 的west 清单（west manifest）中列出的各个 west 项目（west projects）（模块），包括硬件抽象层（HAL）、库等。

    west init -m https://github.com/zephyrproject-rtos/zephyr ~/zephyrproject
cd ~/zephyrproject
west update

    west init -m https://github.com/zephyrproject-rtos/zephyr ~/zephyrproject
cd ~/zephyrproject
west update

    west init -m https://github.com/zephyrproject-rtos/zephyr zephyrproject
cd zephyrproject
west update

    提示

    要减少磁盘占用，并避免在搭建环境时下载不需要的模块或厂商 HAL，可以在运行 west update 前配置项目组（project groups）。

  5. 安装 Zephyr 的 Python 依赖项：

    west packages 从当前检出的 Zephyr 工作区（包括其模块）读取 Python 依赖要求，因此安装的软件包与所获取的 Zephyr 版本相匹配。

    west packages pip --install

    west packages pip --install

    cmd /c zephyr\scripts\utils\west-packages-pip-install.cmd

    python -m pip install @((west packages pip) -split ' ')

    说明

    安装这些依赖项也可能使 west 本身降级或升级。

  6. 导出 Zephyr CMake 软件包。这会将当前检出的 Zephyr 登记到 CMake 的用户软件包注册表中，以便构建应用时由 find_package(Zephyr) 自动找到它。

    west zephyr-export

安装 Zephyr SDK

Zephyr 软件开发套件（Zephyr SDK） 包含适用于 Zephyr 各受支持架构的工具链（toolchain）。每套工具链包含编译器、汇编器、链接器，以及为目标硬件构建 Zephyr 应用所需的其他程序。

SDK 还包含其他主机工具，例如定制构建的 QEMU 和 OpenOCD，可用于仿真、烧写和调试 Zephyr 应用。

在 Zephyr 仓库目录中运行 west sdk install 安装 Zephyr SDK：

cd ~/zephyrproject/zephyr
west sdk install

cd ~/zephyrproject/zephyr
west sdk install

cd %HOMEPATH%\zephyrproject\zephyr
west sdk install

cd $Env:HOMEPATH\zephyrproject\zephyr
west sdk install

提示

你可以通过命令选项指定 SDK 的安装位置，或仅安装所选架构的工具链。详情见 west sdk install --help。

说明

如果不想通过 west sdk 命令安装 Zephyr SDK，请参阅Zephyr SDK 安装说明。

构建 Blinky 示例

说明

Blinky 适用于大多数支持的开发板与扩展板，但并非全部。如果你的开发板不满足 Blinky 的硬件要求，可以改用 Hello World 示例。

如果不确定 west 如何称呼你的开发板，可用 west boards 列出 Zephyr 支持的所有开发板。开发板目录中的板卡页面也会给出传给 west build 的准确板级目标（board target）名称。

使用 west build 构建 Blinky 示例。请将 <your-board-name> 替换为你的开发板名称：

cd ~/zephyrproject/zephyr
west build -p always -b <your-board-name> samples/basic/blinky

cd ~/zephyrproject/zephyr
west build -p always -b <your-board-name> samples/basic/blinky

cd %HOMEPATH%\zephyrproject\zephyr
west build -p always -b <your-board-name> samples\basic\blinky

cd $Env:HOMEPATH\zephyrproject\zephyr
west build -p always -b <your-board-name> samples\basic\blinky

-p always 选项会强制执行干净构建（pristine build），删除此前配置生成的构建产物，避免入门时受旧文件影响。熟悉之后，可改用 -p auto，让 west build 根据启发式规则判断是否需要干净构建。详情见 west build -h。

说明

一块开发板可包含一个或多个片上系统（SoC），每个 SoC 又可包含一个或多个 CPU 簇（CPU cluster）。为这类开发板构建示例时，需要指定目标 SoC 或 CPU 簇。例如，要在 nRF5340 DK 的 cpuapp 核上运行 Blinky，必须将板级目标指定为 nrf5340dk/nrf5340/cpuapp。另请参阅开发板术语。

烧写示例

连接开发板（通常通过 USB）；如果板上有电源开关，请打开。如果不确定如何操作，请查看支持的开发板与扩展板中对应的板卡页面：有些开发板在烧写前需要特定的设置或操作步骤。

使用 west flash 烧写示例。这会将刚构建的应用写入已连接的开发板：

west flash

说明

你的开发板可能还需要安装其他主机工具。如果缺少必要的依赖项，west flash 会输出错误信息。

说明

在 Linux 上，第一次用调试探针（debug probe）烧写之前，可能需要配置 udev 规则。请参阅设置 udev 规则。

后续学习

你可以从以下几个方向继续探索 Zephyr：

  • 尝试其他示例与演示。

  • 了解应用开发以及 west 工具。

  • 了解 west 的烧写和调试功能，或深入阅读烧写与硬件调试。

  • 阅读入门之后，了解搭建环境的其他方式与思路。

  • 查看社区资源，了解如何向 Zephyr 社区求助。

如何求助

求助前，请先搜索本文档、Zephyr 项目的 GitHub 讨论和议题，以及 Discord 聊天记录，看看是否已经有人回答过你的问题。你也可以向英文官网各文档页面上的聊天机器人（chatbot）提问。

  • 邮件列表：需要求助时，通常应选择 users@lists.zephyrproject.org 列表。可在此搜索归档并订阅。

  • GitHub：请到 GitHub 讨论区（Discussions） 提问；报告缺陷或提交功能请求请用 GitHub 议题（Issues）。

  • Discord：可通过此Discord 邀请链接加入。

求助时，请提供以下信息：

  1. 你想完成什么；

  2. 你试过哪些操作，包括执行过的命令；

  3. 实际发生了什么，包括完整的文本输出。

请直接复制并粘贴文本，不要用截图代替。在 Discord 或 GitHub 上分享超过 5 行的终端输出、源代码或日志时，请用三个反引号将内容围成代码块。
