安装 west

非官方简体中文译本 · 英文基线 4.5.99 · A07 · 全站目录（79 篇） · A 批目录 · 本页英文原文

west 用 Python 3 编写，通过 PyPI 分发。使用 pip3 可以安装或升级 west：

在 Linux 上：

pip3 install --user -U west

在 Windows 和 macOS 上：

pip3 install -U west

说明

有关 --user 选项的使用说明，见Python 与 pip。

安装后，可运行 pip3 show -f west 查看 west 可执行文件及相关文件的安装位置。

安装 west 后，即可用它克隆 Zephyr 仓库。

程序结构

west 的代码通过 PyPI 分发，Python 包名为 west。包中包含一个启动程序（launcher），同样名为 west（Windows 上为 west.exe）。

安装时，pip3 会将启动程序放入用户文件系统。具体位置因操作系统而异，但应位于 PATH 环境变量所列的目录中。这个启动程序是统一的命令行入口，既可运行 west init、west update 等内置命令，也可运行在工作区中发现的扩展命令。

除命令行接口外，还可以直接使用 west 的 Python API。详见 west API。

启用 shell 自动补全

west 支持以下 shell 的自动补全：

  • bash

  • zsh

  • fish

  • powershell（仅支持开发板限定符）

要启用自动补全，需先取得对应的补全脚本，再让当前 shell 加载它。各 shell 的用法如下：

仅在当前会话中启用:

source <(west completion bash)

永久启用:

west completion bash > ~/west-completion.bash; printf '\n%s\n' "source ~/west-completion.bash" >> ~/.bashrc

仅在当前会话中启用:

source <(west completion zsh)

永久启用:

west completion zsh > "${fpath[1]}/_west"

仅在当前会话中启用:

west completion fish | source

永久启用:

west completion fish > $HOME/.config/fish/completions/west.fish

仅在当前会话中启用:

west completion powershell | Out-String | Invoke-Expression

永久启用:

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
New-item -type file -force $PROFILE
west completion powershell > $HOME/west-completion.ps1
(Add-Content -Path $PROFILE -Value ". '{$HOME/west-completion.ps1}'")
