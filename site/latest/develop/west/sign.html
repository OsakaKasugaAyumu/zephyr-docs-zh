二进制文件签名（Signing Binaries）

非官方简体中文译本 · 英文基线 4.5.99 · D05（west sign 命令） · 全站目录（79 篇） · D 批目录 · 本页英文原文

west sign 扩展命令可调用外部工具，为供引导程序加载的 Zephyr 应用二进制文件签名。某些配置也使用 west sign 调用外部后处理工具，将各部分“拼接”为最终镜像。运行 west sign -h 可查看命令行帮助。

rimage

rimage 使用 west config 配置，而不依赖 Kconfig 或 CMake，做法类似于持久设置 CMake 参数。

签名流程由多层脚本包装：west flash 调用 west build，后者运行 cmake 和 ninja，再由构建工具调用 west sign，最终调用 imgtool 或 rimage。若参数始终采用默认值，这些间接调用通常没有问题。要把 imgtool 或 rimage 的选项一路透传下去则较麻烦：每层都要加转发代码；带空格或特殊字符的参数不易正确引用。排查构建问题时，要复现底层的 west sign 命令，往往得先启用详细日志、再查找实际选项；即使复制命令，也可能因环境细微差异而产生不同结果。更重要的是，在每一层都增加转发逻辑之前，新签名功能和选项根本无法使用。

为避免上述问题，可在 west config 中设置 rimage 参数。下面是一份 workspace/.west/config 示例：

[sign]
# Not needed when invoked from CMake
tool = rimage

[rimage]
# Quoting is optional and works like in Unix shells
# Not needed when rimage can be found in the default PATH
path = "/home/me/zworkspace/build-rimage/rimage"

# Not needed when using the default development key
extra-args = -i 4 -k 'keys/key argument with space.pem'

为了支持引号，参数值使用 Python 的 shlex.split() 解析，方式与仅本次使用的 CMake 参数一致。

extra-args 直接传给 rimage。上例等同于在命令行 -- 后追加这些参数，即 west sign --tool rimage -- -i 4 -k 'keys/key argument with space.pem'。如果两种方式同时使用，命令行参数排在最后。

silabs_commander

silabs_commander 工具用于给 Silicon Labs 设备的二进制文件签名、添加消息完整性码（MIC）或加密。若 sign.tool 设为 silabs_commander，可由 west sign 调用；若设置了 CONFIG_SIWX91X_SIGN_KEY 或 CONFIG_SIWX91X_MIC_KEY，也可由 west build 调用。

只要设置了 CONFIG_SIWX91X_SIGN_KEY 或 CONFIG_SIWX91X_MIC_KEY，west flash 就会自动烧写签名版本。

使用 silabs_commander 前，主机上必须安装 Simplicity Commander。在设备上预置密钥的方法见UG574：SiWx917 SoC 生产工具用户指南。
