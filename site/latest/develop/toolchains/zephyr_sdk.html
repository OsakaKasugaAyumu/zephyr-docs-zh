Zephyr SDK

非官方简体中文译本 · 英文基线 4.5.99 · A05 · 全站目录（79 篇） · A 批目录 · 本页英文原文

Zephyr 软件开发工具包（Software Development Kit，SDK）包含面向各个受支持架构的 GNU 和 LLVM 工具链（toolchain），还提供定制的 QEMU、OpenOCD 等主机工具。

强烈建议使用 Zephyr SDK。在某些条件下它甚至是必需的，例如在 QEMU 中对某些架构运行测试时。

支持的架构

Zephyr SDK 支持下列目标架构：

  • ARC（32 位和 64 位；ARCv1、ARCv2、ARCv3）

  • ARM（32 位和 64 位；ARMv6、ARMv7、ARMv8；A/R/M 系列）

  • Microblaze（32 位）

  • MIPS（32 位和 64 位）

  • RISC-V（32 位和 64 位；RV32I、RV32E、RV64I）

  • RX

  • SPARC（32 位和 64 位；SPARC V8、SPARC V9）

  • x86（32 位和 64 位）

  • Xtensa

安装包与环境变量

Zephyr SDK 安装包以压缩文件形式分发，支持 Linux、macOS 和 Windows 三大主机操作系统。

为方便分发，SDK 提供三种预打包版本供下载：

安装分两步：解压下载的安装包，然后运行其中的设置脚本。

无论下载哪种安装包，安装时都会询问要安装哪些工具链。如果运行脚本的本地目录中找不到所选工具链，脚本会在安装过程中下载。也可以事先下载 GNU 和 LLVM 两个 SDK 安装包，将它们解压到同一目录树；这样就能同时安装两者，无需在脚本运行期间再下载。

各操作系统的补充说明见下文。

若未选择工具链，构建系统会查找 Zephyr SDK 并使用其中的工具链。可以将环境变量 ZEPHYR_TOOLCHAIN_VARIANT 设为 zephyr，强制使用此选择。

如果没有将 Zephyr SDK 安装在默认位置（见下文各操作系统的说明），但希望构建系统自动找到它，就必须运行设置脚本，将 SDK 注册到 CMake 包注册表（package registry）。如果选择不注册，则可通过 ZEPHYR_SDK_INSTALL_DIR 指向 SDK 的安装目录。

也可以让 ZEPHYR_SDK_INSTALL_DIR 指向包含多个版本 Zephyr SDK 的目录，以便自动选择工具链。例如，可将 ZEPHYR_SDK_INSTALL_DIR 设为 /company/tools，并在 company/tools 目录下放置以下子目录：

  • /company/tools/zephyr-sdk-0.13.2

  • /company/tools/zephyr-sdk-a.b.c

  • /company/tools/zephyr-sdk-x.y.z

这样可以将多个 SDK 集中存放在指定路径，同时让 Zephyr 构建系统选择正确版本。

Zephyr SDK 版本兼容性

一般而言，本页引用的 Zephyr SDK 版本就是相应 Zephyr 版本的推荐搭配。

Zephyr 与 Zephyr SDK 各版本的完整兼容关系列在Zephyr SDK 版本兼容性矩阵中。

安装 Zephyr SDK

说明

如有需要，可将下文命令中的 1.0.1 替换为其他版本。Zephyr SDK 发行版页面列有所有可用的 SDK 发行版。

说明

以下说明使用 Zephyr GNU SDK 安装包，其中含所有受支持架构的 GNU 工具链和主机工具。若使用 Zephyr LLVM SDK 安装包，请将包文件名中的 _gnu 后缀改为 _llvm。

说明

要卸载 SDK，只需删除它的安装目录。

  1. 下载并校验 Zephyr SDK 安装包：

    cd ~
wget https://github.com/zephyrproject-rtos/sdk-ng/releases/download/v1.0.1/zephyr-sdk-1.0.1_linux-x86_64_gnu.tar.xz
wget -O - https://github.com/zephyrproject-rtos/sdk-ng/releases/download/v1.0.1/sha256.sum | shasum --check --ignore-missing

    若主机为 64 位 ARM 架构（例如 Raspberry Pi），请将 x86_64 换成 aarch64，以下载适用的 64 位 ARM Linux SDK。

  2. 解压 Zephyr SDK 安装包：

    tar xvf zephyr-sdk-1.0.1_linux-x86_64_gnu.tar.xz

    说明

    建议将 Zephyr SDK 安装包解压到以下位置之一：

    • $HOME

    • $HOME/.local

    • $HOME/.local/opt

    • $HOME/bin

    • /opt

    • /usr/local

    Zephyr SDK 压缩包内含 zephyr-sdk-<version> 目录。如果将其解压到 $HOME 下，最终的安装路径是 $HOME/zephyr-sdk-<version>。

  3. 运行 Zephyr SDK 安装包中的设置脚本：

    cd zephyr-sdk-1.0.1
./setup.sh

    说明

    解压 Zephyr SDK 安装包后，只需运行一次设置脚本。

    如果在初次设置后移动了 Zephyr SDK 目录，就必须重新运行设置脚本。

  4. 安装 udev 规则，以便普通用户也能向大多数 Zephyr 开发板烧写程序：

    sudo cp ~/zephyr-sdk-1.0.1/hosttools/sysroots/x86_64-pokysdk-linux/usr/share/openocd/contrib/60-openocd.rules /etc/udev/rules.d
sudo udevadm control --reload

curl -L -O https://github.com/zephyrproject-rtos/sdk-ng/releases/download/v1.0.1/zephyr-sdk-1.0.1_macos-aarch64_gnu.tar.xz

  1. 以普通用户身份打开 cmd.exe 终端窗口。

  2. 下载 Zephyr SDK 安装包：

    cd %HOMEPATH%
wget https://github.com/zephyrproject-rtos/sdk-ng/releases/download/v1.0.1/zephyr-sdk-1.0.1_windows-x86_64_gnu.7z

  3. 解压 Zephyr SDK 安装包：

    7z x zephyr-sdk-1.0.1_windows-x86_64_gnu.7z

    说明

    建议将 Zephyr SDK 安装包解压到以下位置之一：

    • %HOMEPATH%

    • %PROGRAMFILES%

    Zephyr SDK 压缩包内含 zephyr-sdk-<version> 目录。如果将其解压到 %HOMEPATH% 下，最终的安装路径是 %HOMEPATH%\zephyr-sdk-<version>。

  4. 运行 Zephyr SDK 安装包中的设置脚本：

    cd zephyr-sdk-1.0.1
setup.cmd

    说明

    解压 Zephyr SDK 安装包后，只需运行一次设置脚本。

    如果在初次设置后移动了 Zephyr SDK 目录，就必须重新运行设置脚本。
